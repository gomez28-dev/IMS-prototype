# Brainstorming & Requirements Alignment

Use this skill when tackling non-trivial features, architectural refactors, or ambiguous requirements to align on the best technical direction before implementation.

## Workflow

1. **Clarify Intent & Constraints**:
   - Parse user requirements and inspect related code and documentation.
   - Identify implicit constraints (e.g. Laravel 11, Hostinger shared hosting limitations, role permissions).
2. **Explore Multiple Approaches**:
   - Formulate 2–3 viable architectural or implementation approaches.
   - Contrast trade-offs: simplicity, performance, maintainability, and deployment safety.
3. **Present Options Concisely**:
   - Summarize options clearly for the user without technical fluff.
   - Recommend the most pragmatic path with clear rationale.
4. **Obtain Alignment**:
   - Wait for user confirmation before moving on to detailed planning or implementation.
